# Hand Jutsu

@Metadata {
   @TechnologyRoot

SwiftUI, RealityKit, ARKit을 사용해 Apple Vision Pro에서 양손을 추적하고, 손 모양 판정에 필요한 관절 데이터를 만드는 과정을 배운다.

![양손 관절 데이터가 Hand Jutsu 튜토리얼 흐름으로 이어지는 개념 이미지](hand-jutsu-overview.svg)

## Overview

Hand Jutsu는 손을 단순한 입력 장치가 아니라 공간 안의 데이터로 이해하기 위한 visionOS 튜토리얼이다.

첫 번째 버전에서는 화려한 공간 효과보다 Immersive Space, Hand Tracking, 관절 좌표 변환과 Pose Features 입력 흐름을 차근차근 이해하는 데 집중한다.
